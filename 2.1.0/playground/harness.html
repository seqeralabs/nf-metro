Import Nextflow DAG

Paste a Nextflow -with-dag Mermaid file to convert it into a starting metro map. Generate one with nextflow run <pipeline> -preview -with-dag dag.mmd — see the Nextflow import guide.

Attach a logo

Embeds the image directly into the %%metro logo: directive as inline data, so it travels with the map text. The playground runs entirely in your browser and cannot read a logo file from your computer's disk by path.

This image is large; embedding it will make the map source (and any share link) much bigger. A small logo (under ~50 KB) works best.
